# Hoàng Anh Kiệt — Social Media Website

Website tĩnh phong cách gaming/neon, phù hợp GitHub Pages và điện thoại.

## File trong dự án
- `index.html` — cấu trúc trang.
- `style.css` — giao diện, màu sắc và responsive.
- `script.js` — menu di động, chọn nền tảng, tạo và sao chép bản nháp.
- `assets/hero-banner.jpg` — banner trang chủ.
- `assets/favicon.svg` — biểu tượng website.

## Đưa website lên GitHub Pages bằng điện thoại
1. Đăng nhập GitHub và tạo repository mới, ví dụ `hoang-anh-kiet-social`.
2. Chọn repository → **Add file** → **Upload files**.
3. Tải lên `index.html`, `style.css`, `script.js`, thư mục `assets` (gồm cả hai file bên trong) và `README.md`.
4. Nhấn **Commit changes**.
5. Vào **Settings** → **Pages**.
6. Trong phần **Build and deployment**, chọn **Deploy from a branch**.
7. Chọn branch `main`, thư mục `/(root)`, rồi nhấn **Save**.
8. Đợi GitHub Pages hoàn tất và mở đường dẫn hiển thị trong trang Pages.

## Trước khi dùng thật
- Bảng giá hiện là mẫu “Liên hệ”, không phải giá dịch vụ đã xác nhận.
- Form chỉ tạo bản nháp trên trình duyệt; nó KHÔNG gửi đơn, email hay Telegram.
- Muốn nhận đơn thật, hãy kết nối backend hoặc dịch vụ form đáng tin cậy. Không để bot token, mật khẩu hay khóa API trong JavaScript công khai.
- Thay thông tin liên hệ và chính sách dịch vụ bằng thông tin thật trước khi công khai.
- Chỉ cung cấp dịch vụ hợp lệ, tuân thủ điều khoản của từng nền tảng mạng xã hội.

## Tuỳ chỉnh nhanh
- Nội dung: sửa trong `index.html`.
- Màu sắc và bố cục: sửa biến CSS ở đầu `style.css`.
- Tương tác form/menu: sửa `script.js`.
- Banner: thay `assets/hero-banner.jpg` bằng ảnh bạn có quyền sử dụng, giữ nguyên tên file hoặc cập nhật đường dẫn trong CSS.
